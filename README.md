# E‑Commerce Araby

## تشغيل محلي (Local)
```bash
npm install
npm run dev
```

## معاينة الإنتاج
```bash
npm run build
npm run preview
```

## النشر على GitHub Pages
- تأكد أن اسم المستودع: **e-commerce-araby**
- GitHub Pages → Deploy from branch → `/dist`


## نشر تلقائي
✔️ أي Push إلى main ينشر الموقع تلقائياً على GitHub Pages.
